### Sub-task 2: Create `audit_runner.sh` — multi-agent on-demand (~30 min)

**File**: `audit_runner.sh` (NEW, in repo root, `chmod +x`)

**Pattern**: mirror `guardian_cron.sh` style (header, log(), flock, env vars) tapi launch N background processes untuk parallel.

**Skeleton**:
```bash
#!/bin/bash
# Multi-agent on-demand audit runner
# Usage: ./audit_runner.sh --agents 7 [--batch 20] [--create-issues]
#
# Default: 7 agents × 20 files = 140 files in one run
# flock mutual exclusion (Lesson #12)
# Per-agent state files, atomic write
# Posts comments to profile issues for ambiguous (if --create-issues)

set -euo pipefail

WORKDIR="/home/ubuntu/profilasatidz"
LOGDIR="$WORKDIR/osint_archive"
LOCKFILE="$LOGDIR/audit_runner.lock"
MAX_AGENTS=7
BATCH_PER_AGENT=20
CREATE_ISSUES=0
TODAY=$(TZ=Asia/Jakarta date +%Y-%m-%d)
LOGFILE="$LOGDIR/audit_runner-${TODAY}.log"

# Parse args (use getopt or manual)
while [[ $# -gt 0 ]]; do
    case "$1" in
        --agents) MAX_AGENTS="$2"; shift 2 ;;
        --batch) BATCH_PER_AGENT="$2"; shift 2 ;;
        --create-issues) CREATE_ISSUES=1; shift ;;
        *) echo "Unknown arg: $1"; exit 1 ;;
    esac
done

cd "$WORKDIR"
log() { echo "[$(TZ=Asia/Jakarta date '+%Y-%m-%d %H:%M:%S')] $*" | tee -a "$LOGFILE"; }

# flock
exec 200>"$LOCKFILE"
if ! flock -n 200; then
    log "Skip: another audit_runner is already running"
    exit 0
fi

log "=== Multi-agent audit start: agents=$MAX_AGENTS batch=$BATCH_PER_AGENT ==="

# Launch N agents
PIDS=()
for ((i=0; i<MAX_AGENTS; i++)); do
    /usr/bin/python3 "$WORKDIR/audit_corruption.py" \
        --detail-dir "$WORKDIR/detail" \
        --state-dir "$LOGDIR" \
        --quarantine-dir "$LOGDIR/quarantine" \
        --batch "$BATCH_PER_AGENT" \
        --agents "$MAX_AGENTS" \
        --agent-id "$i" \
        2>>"$LOGFILE" >>"$LOGFILE" &
    PIDS+=($!)
done

# Wait
FAILED=0
for pid in "${PIDS[@]}"; do
    if ! wait "$pid"; then
        FAILED=$((FAILED + 1))
    fi
done

log "=== Multi-agent run done (failed=$FAILED) ==="

# Merge states
/usr/bin/python3 "$WORKDIR/audit_corruption.py" --merge-states --state-dir "$LOGDIR" 2>&1 | tee -a "$LOGFILE"

# Post GH comments if requested
if [ "$CREATE_ISSUES" -eq 1 ]; then
    log "=== Posting audit comments to profile issues ==="
    /usr/bin/python3 "$WORKDIR/post_audit_comment.py" --state-dir "$LOGDIR" 2>&1 | tee -a "$LOGFILE"
fi

# Trim log if too big
SIZE=$(stat -f%z "$LOGFILE" 2>/dev/null || stat -c%s "$LOGFILE" 2>/dev/null || echo 0)
if [ "$SIZE" -gt 10485760 ]; then
    tail -5000 "$LOGFILE" > "${LOGFILE}.tmp"
    mv "${LOGFILE}.tmp" "$LOGFILE"
fi
```

## Risk Notes (gotchas to watch for)

1. **GH API rate limit**: 5000 req/hour authenticated. Posting ~13 comments + 13 label adds = 26 calls. Well within limit. But if sweep finds 100+ ambiguous, batch carefully.
2. **`gh` CLI may need re-auth**: if session expired, will fail. Add `gh auth status` check at start of `post_audit_comment.py`.
3. **Python 3.9 string union**: `str | None` only works with `from __future__ import annotations`. Already used in `audit_corruption.py`, copy pattern to new files.
4. **`os.Rename` on bind mount** (Lesson #5): quarantine uses `os.WriteFile` + `os.remove`, not `os.Rename`. Already correct in `quarantine_file()`.
5. **Race condition on state file** (Lesson #12): per-agent state files + flock on runner. Don't have agents write to same file.
6. **NPTL/SSH hangs** on long-running scripts: use `flock` non-blocking + `timeout` in wrapper. The previous test that hung was the cron wrapper's intentional 0-15m sleep — runner doesn't have that sleep.
7. **Idempotency marker**: use date + verdict in marker (`## Audit Corrupt — 2026-06-07 — ambiguous`) so re-runs on same day don't double-post, but new day gets fresh comment.
8. **Profile issue already closed**: skip if `state:open` filter returns nothing. Don't reopen closed issues.
