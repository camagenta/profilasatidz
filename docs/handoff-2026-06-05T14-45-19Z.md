# Handoff — 2026-06-05 (Session 1: KajianLive OSINT Enrichment)

## Goal
- Dokumentasikan proses OSINT (Open Source Intelligence) untuk data asatidz dengan menyandingkan data Kajian.net ↔ KajianLive.my.id, lakukan enrichment, dan format dokumentasi GitHub Issue per asatidz (Body = Profil Live + Status Profiling; Comments = histori perubahan).

## Constraints & Preferences
- Polite scraping dengan random delay (2.0–5.0 detik) antar request
- Batch processing (10 ustadz per batch)
- Encoding fix untuk halaman non-UTF-8 (gunakan `bytes.decode('utf-8', errors='replace')`)
- Git commit style: `feat(osint): ...`, `fix(osint): ...`
- Jangan commit `__pycache__/`
- Setiap GitHub Issue per asatidz: Body berisi Profil Live (bio, foto, pendidikan, karya) + Status Profiling; Komentar berisi log histori perubahan
- Threshold match: `match_score >= 1.0` untuk enrichment
- **Wajib**: Setiap handoff/sesi harus disimpan ke `docs/handoff-{timestamp}.md` dan di-commit-push ke git sebelum sesi berakhir
- **Wajib**: Agent berikutnya WAJIB membaca handoff terbaru di `docs/` sebelum mulai bekerja
