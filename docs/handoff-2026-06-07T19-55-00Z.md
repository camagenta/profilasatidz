## Lessons Learned (jangan diulang!)

### Lesson #14: Wikipedia enrichment bisa return wrong page
Generic names (e.g., "Muhammad", "Ahmad", "Islam") ketika di-enrich via Wikipedia search akan return halaman Nabi Muhammad atau tokoh terkenal, bukan ustadz yang dimaksud. **Detection**: cek apakah first sentence bio match dengan search query (NFKC-normalized). Jika bio tentang "Nabi Muhammad" dan search query adalah "Muhammad Zaki", itu CORRUPTION. **Prevention**: enrich script harus verify name match di title atau first paragraph sebelum save.

### Lesson #15: Audit itu point-in-time, bukan continuous
Sesi audit sebelumnya (e9ab753) sudah clear 84 corrupt bio dari 144 audited. Tapi SESSION BERIKUTNYA bisa create corruption baru (terbukti: `detail/kajian-muhammad-zaki.json` corrupt di server, untracked, post-audit). **Re-audit cadence**: kalau ada nyicil_review run yang tambah file baru, audit ulang batch yang baru masuk. Atau better: integrate corruption check di dalam enrich script itu sendiri (fail fast sebelum write file).
