## Key Decisions
- **JSON key reordering**: Go `json.MarshalIndent` untuk `map[string]interface{}` mengurutkan keys secara alfabetis. Ini mengubah format file tapi tidak mengubah data. Keputusan: diterima sebagai konsekuensi teknis.
- **Atomic write fallback**: `os.Rename` gagal di Docker bind mount dengan error "device or resource busy". Solusi: fallback ke `os.WriteFile` langsung.
- **Detail edit via map**: Detail ditulis sebagai `map[string]interface{}` untuk mempertahankan field tidak dikenal (seperti `enriched_at`, `method`) yang tidak ada di struct `Asatidz`.
