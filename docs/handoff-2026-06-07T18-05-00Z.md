## Lessons Learned (jangan diulang!)
1. **Field mapping harus eksplisit**: `else` branch yang append-to-bio adalah jebakan. Selalu buat explicit handler untuk setiap field yang mungkin dikontribusi user.
2. **Quality check untuk URL replacement**: thumb ≠ full-size. Cek path sebelum replace URL existing.
3. **Master dan detail harus sync**: kontribusi yang update `detail/{id}.json` saja tanpa update `master.json` akan membuat flag `has_*` di master jadi stale. Selalu sync kedua file.
4. **Local testing harus handle path hardcoded**: script yang ditulis untuk server production sering hardcode path (`/home/ubuntu/`, container name). Untuk test di local, butuh fallback path atau env var override.
5. **Bug ditemukan lewat simulasi, bukan test unit**: kasus Abdul Hakim menunjukkan value dari end-to-end manual trace. Code yang "kelihatan benar" tetap bisa punya bug logika yang tidak ke-cover unit test.
