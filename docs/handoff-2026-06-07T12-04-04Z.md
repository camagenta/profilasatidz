## Key Decisions

### NFKC unicode normalization
Nama Arabic dengan combining chars perlu `unicodedata.normalize('NFKC', ...)` agar dianggap nama yang sama saat search. Diterapkan di `findGitHubIssue`, `cleanup_duplicate_issues`, dan `profile_issue_guardian`.

### findGitHubIssue state filter
Tambah `state:open` + `sort=created&order=desc` agar FE return issue terbaru yang OPEN. Sort by created DESC agar saat duplikat, issue terbaru (body lebih lengkap) yang di-prioritaskan.

### Cleanup prefer OPEN state
Saat sort duplicates, prefer OPEN issue sebagai keeper. Kalau semua closed, log warning dan laporkan untuk manual review — JANGAN auto-clean (bisa close keeper yang sebenarnya penting).

### Bio corruption audit
84 profil dengan bio corrupted dari 3 pattern berbeda. Heuristic untuk tight detection:
- "Gambar bawah" image caption → clear
- Wikipedia redirect + own name not in first sentence → clear
- First sentence tentang orang lain (substantive text) → clear

### Tidak rebuild issue body 84 profil di sesi ini
84 sequential `gh issue edit` + 3s delay = 4-5 menit. Bisa dilakukan di next session via background script atau guardian auto-rebuild.

### Cron schedule stagger
`0 */6 * * *` = jam 0, 6, 12, 18 UTC (= 7, 13, 19, 01 WIB). Stagger dengan nyicil_review (jam 16 UTC) agar tidak overlap.
