# Handoff — 2026-06-06T09-33-37Z (Community Contribution Feature)

## Goal
- Implementasi fitur kontribusi/koreksi komunitas (crowdsourcing) yang terintegrasi dengan GitHub Issues masing-masing profil asatidz.

## Constraints & Preferences
- Komunikasi backend dengan GitHub API menggunakan `GITHUB_TOKEN` melalui environment variable.
- Rate limiting sederhana (1 submission per profil per 60 detik) untuk mencegah spamming.
- Form Kontribusi diletakkan di bagian bawah detail profil secara collapsible/kondisional.
- Git commit style: `feat(contrib): ...`, `fix(contrib): ...`, `docs(handoff): ...`.

## Progress
### Done
- Menganalisis codebase untuk menentukan rancangan fitur kontribusi.
- Menambahkan backend endpoint `POST /api/contribute` di `main.go`.
- Menambahkan helper functions (`findGitHubIssue`, `postGitHubComment`) untuk mencari issue dengan query title matching `[Profil Asatidz] {profile_name}` dan memposting kontribusi sebagai comment di issue tersebut.
- Mendesain UI form kontribusi di `renderDetailProfile()` lengkap dengan dropdown bidang kontribusi, textarea isi kontribusi, input referensi URL, dan nama kontributor.

Hal ini menghindari perlunya file mapping statis tambahan di lokal.
- **Collapsible UI**: Form kontribusi disembunyikan secara default dengan tombol toggle untuk menjaga kerapian visual detail modal.
- **Double quote nesting fix**: Mengubah template string literal JavaScript dari backticks (`` ` ``) ke single quotes dan string concatenation agar tidak berbenturan dengan backtick string literal milik Go.
